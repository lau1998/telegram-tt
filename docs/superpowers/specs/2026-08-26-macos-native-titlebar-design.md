# macOS 原生标题栏设计

## 目标

将 Tauri 打包的 macOS 应用窗口改为标准的原生标题栏：红、黄、绿窗口控制按钮始终位于窗口顶部，网页内容不再延伸到标题栏区域。主界面的面板外边距和面板间距统一为 `0.625rem`（10px）。

## 范围

- 仅修改 macOS Tauri 窗口的标题栏行为和 macOS Tauri 主界面布局
- 保留系统原生窗口控制、拖动、缩放、全屏和辅助功能行为
- Web、Windows、Linux、Android 和 iOS 的界面与窗口行为保持不变

## 实现

### 窗口行为

- 新建 macOS 窗口使用可见的原生标题栏，不使用 `Overlay` 标题栏
- 原生标题栏显示 `Telegram Air`，交通灯按钮由 macOS 在顶部标题栏中管理
- 窗口状态不再在主界面、通话面板和其他视图之间切换为 `Overlay`
- 删除只为叠加标题栏交通灯定位服务的 macOS 原生重定位逻辑

### 前端布局

- 移除 macOS Tauri 专用的 `--window-controls-width` 内容预留，因为窗口控制按钮不再覆盖网页
- macOS Tauri 的主面板与窗口边缘、以及相邻主面板之间的外边距统一为 `0.625rem`
- 保持非 macOS 平台的现有 `1rem` 岛式布局，以及移动断点下的现有定位方式

## 状态与兼容性

- 全屏状态仍由 Tauri 原生窗口 API 控制
- 通话、媒体查看、认证等现有页面不再触发标题栏样式变化
- 窗口标题和通知计数继续通过现有 Tauri 命令更新

## 验证

1. 使用 Apple Silicon 目标打包并启动 macOS 测试包
2. 确认交通灯按钮位于原生窗口顶栏，且页面不会在其下方渲染
3. 确认聊天、搜索、设置、通话和全屏切换后标题栏保持正确
4. 确认主面板外边距及面板间距均为 10px
5. 运行 TypeScript 与 SCSS 检查
